Timeline:
  • Click to use

  • Use mouse wheel to scroll up & down

  • Use ctrl + mouse wheel to zoom in & out

  • Pan left / right to move in time

  • Hover on any event to see additional info

  • Double click on any event to create time-based annotations in the interconnected line chart widgets below

  • The available widgets are timewise synchronised

Details Table:
  • Type any text in the filter bar to search through the displayed information in the table

  • Sort accordingly by any column of the table

Line Chart:
  • Zoom, Pan, Reset and Download the visualised data

  • The available line charts are timewise synchronised

Network Graph:
  • Click to use

  • Use mouse wheel to zoom in & out

  • Hover on any edge or node to see additional info

  • Double click on any node to add the corresponding Speaker in the Details Widget

  • Double click on any edge to add the included conversations in the Details Widget

  • unfold_more Adjust Widget size


  • Yellow color represents selected entities in filters

  • Red color represents the most / less interracted entities
